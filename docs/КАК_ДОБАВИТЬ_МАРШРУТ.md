# Как добавить маршрут: на примере P «Пилот у партнёра»

Маршрут P в игре уже виден, но закрыт. Чтобы его открыть, нужно поменять данные и правила, а движок и экраны трогать не придётся.

## 1. Правила: `src/engine/rules.js`

1. Уберите `'P'` из `NEXT_VERSION`. В `planAvailability` откройте P при `s.offers.pilot === 'taken'` и задайте причину закрытия `plan.needPilot`.
2. В `ledger` опишите расходы P по сценарию: Connaught платит за первую оценку 1, натура `kind` равна 6, а две оставшиеся свободные единицы игрок отдаёт на исследование и передачу метода.
3. В `resolveFinal` добавьте `if (s.plan === 'P') return s.s9 ? 'p' : null;` и в `stepAfterSign` укажите шаг S8 для P.
4. В `guardRoute` разрешите S8 и S9 для P.

## 2. Состояние: `src/engine/state.js`

В `OFFER_VALUES.pilot` добавьте значение `'taken'`.

## 3. Данные: `src/content/missions/insulin/`

- **`scenes.js`, сцена `s5`:** у карточки пилота уберите `next = true` и верните решение «Взять в рабочую папку» с эффектом `{ type: 'offer', key: 'pilot', value: 'taken' }`.
- **`scenes.js`, S8 и S9:** добавьте вариант для P (Индианаполис, фон `indy`), как это сделано для `s9H`.
- **`plans.js`:** у P уже есть `rows`, добавьте `line` и `cal`.
- **`finals.js`:** добавьте `p`. Текст и фон уже лежат в `mission.data.js` (`finals.p`), строки итога считаются из сметы.
- **`review.js`:** в `opportunities` (`pilot`) уберите пометку «следующая версия», добавьте цепочку `S9P` в `causes` и строки P в `facets`.
- **`texts.ru.js`:** добавьте `plan.needPilot`.

## 4. Тесты

- **`tests/engine.rules.test.js`:** добавьте строки таблицы сценария для P. «P с двумя работами»: свободный остаток 0, натура 6 из 6. «P только с первой оценкой»: свободный остаток 2. Финал в обоих случаях `p`.
- **`tests/content.test.js`:** проверьте, что пресет или полный проход открывает P.
- **`tests/e2e/routes.mjs`:** добавьте маршрут `P` по образцу `H-research`.

Запустите `npm test`, затем `npm run build`, `npx vite preview --port 4173` и `npm run e2e`.

## Новый кейс целиком

Скопируйте папку `src/content/missions/insulin/` под новым именем и замените данные. Затем подключите миссию вместо `insulin` в местах, где она импортируется: `src/main.js`, экраны и `review.js`. Чтобы на карте мира выбиралось несколько миссий, нужен общий список миссий. Это следующий шаг после MVP.
