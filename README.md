# Архитектура финансирования · MVP миссии «Инсулин»

Образовательная игра для руководителей вузов и НИИ. Это интерактивный комикс на историческом кейсе: Торонто, лето 1922 года, игрок в роли Чарльза Беста собирает ресурсы на новый этап работы над инсулином. Решения игрока меняют финал, а личный разбор показывает, какие возможности он использовал и какие упустил.

В MVP проходятся четыре маршрута:

| Маршрут | Что это | Финал |
|---|---|---|
| **H** | Собственная установка и общая проверка с партнёром | S10H |
| **L** | Собственная установка, дилемма последней единицы | S10L (контроль) или S10R (исследование или резерв) |
| **N** | «Восемь после приёмки»: кассовый разрыв | S10N |
| **W** | Остаться на нынешнем объёме, запасной план | S10W |

P (пилот у партнёра) и F (бронь отгрузки) видны в игре, но закрыты: «Маршрут появится в следующей версии».

Для быстрого показа на стартовом экране есть ссылка «Показ маршрутов». Она сразу ставит игрока перед советом S7, все предложения уже собраны.

## Запуск

Нужен Node.js 22.

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

| Команда | Что делает |
|---|---|
| `npm run dev` | Локальный сервер с перезагрузкой |
| `npm test` | Тесты движка и данных миссии (Vitest) |
| `npm run build` | Сборка сайта в `dist/` |
| `npm run preview` | Открыть собранный сайт |
| `npm run e2e` | Пройти все маршруты в браузере. Сначала `npm run build` и `npx vite preview --port 4173` |

## Публикация на GitHub Pages

Сайт собирается и публикуется сам при каждом push в `main` (`.github/workflows/pages.yml`). Один раз владелец репозитория должен включить Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Адрес сайта: `https://<организация>.github.io/<репозиторий>/`.

Проверка `ci.yml` запускает тесты и сборку на каждый push и pull request.

## Где что лежит

```
src/
  engine/      логика игры без интерфейса: состояние, правила, разбор, сохранение
  content/     тексты и данные миссии — правят сценаристы
  ui/          экраны и окна, перенесённые из дизайн-пакета
  styles/      стили дизайн-пакета + app.css (дополнения MVP)
public/        картинки, шрифты, иконки, логотип (имена файлов как в дизайн-пакете)
tests/         тесты движка и данных; tests/e2e — проход маршрутов в браузере
docs/          архитектура, как добавить маршрут, спецификация и план
```

Подробнее: [docs/АРХИТЕКТУРА.md](docs/АРХИТЕКТУРА.md) и [docs/КАК_ДОБАВИТЬ_МАРШРУТ.md](docs/КАК_ДОБАВИТЬ_МАРШРУТ.md).

## Как поправить текст или картинку

- **Подпись кнопки или интерфейса:** `src/content/texts.data.js` (строки дизайн-пакета) или `src/content/texts.ru.js` (новые строки MVP).
- **Реплики, окна, цифры сцен:** `src/content/missions/insulin/mission.data.js`. Это тот же файл, что в дизайн-пакете.
- **Тексты разбора, возможности, историческая справка:** `src/content/missions/insulin/review.js`.
- **Картинка:** положите файл с тем же именем в `public/img/…`. Код менять не нужно.

Источники: сценарий и дизайн-пакет в `Busig-Inc/architecture-financing-game`, концепция в `Busig-Inc/knowledge-base/02_концепт`.
